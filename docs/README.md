## Suggested launch order

1. **Polish the site.** Mobile sweep, fix Spa Island, re-run theory analyzer.
2. **Read all three drafts** carefully and edit voice/details to match your style.
3. **Send mod-mail.** Wait 24–48h.
4. **Post to Reddit** Tuesday/Wednesday morning (US East Coast).
5. **Be in the comments for the first hour.** This is critical — early engagement = visibility.
6. **If post hits 200+ upvotes:** trigger the Liam follow-up.
7. **If post flops:** take it down, gather feedback, revise, retry in 1-2 weeks.

## Pre-launch checklist

- [ ] Site loads cleanly on mobile
- [ ] All `<title>` tags say "The Shimotsuki Codex"
- [ ] Home page numbers are accurate (1,181 chapters / 1,659 SBS / 22 covers)
- [ ] No console errors on any page
- [ ] About page mentions licence, attribution, and contact path
- [x] GitHub repo README is presentable
- [ ] Mod-mail sent and replied to (or 48h elapsed)
- [ ] Reddit username on the account is professional-ish
- [ ] Posting from a clean IP (not VPN that triggers spam filters)
- [ ] Screenshot tool ready for documenting upvote count

## Post-launch checklist

- [ ] Engaging in comments (first 60 min)
- [ ] Tracking upvote velocity (check at 1h, 6h, 24h)
- [ ] Crashes / 404s reported? Fix immediately
- [ ] Save Reddit post link for the Liam outreach
- [ ] If trending → share on Twitter (if you have one)
- [ ] Don't reply to trolls, do reply to genuine critique

## Subreddits in priority order

1. **r/OnePiece** (3.4M) — primary launch
2. **r/OnePieceTheories** (smaller, theory-focused) — cross-post 1-2 weeks later if r/OnePiece succeeded
3. **r/Piratefolk** (snarky theory crowd) — only if you have thick skin and the project is already validated

Avoid posting all three on the same day — Reddit cross-post detection can shadow-ban your account.
